# Kigali Safety Academy Homepage

A responsive, single-page Kigali Safety Academy site built with Next.js and Tailwind CSS. The page follows the structure of the class reference recreation, uses the logo supplied by the user, and replaces the reference organization's visible branding with Kigali Safety Academy. The original account, course, certificate, and checkout backends are not included.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`. Create a production build with `pnpm build`; check TypeScript with `pnpm typecheck`.

The supplied logo is used as provided. Several training photographs remain sourced from the public reference page for this class exercise; the visible header, page copy, campaign banner, and footer are branded for Kigali Safety Academy. Follow your instructor's rules for attribution and reuse of third-party imagery.
